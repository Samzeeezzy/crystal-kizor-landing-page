# Crystal Kizor — Landing Page

Single-page landing page concept for the Web Developer Stage 1 Assessment.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- GitHub Pages-ready static files

## Run locally
Open `index.html` directly in a browser, or use a local static server.

## Deploy
This repository can be published directly with GitHub Pages from the `main` branch and `/` root, or through a GitHub Actions workflow.

## Assets
The Nature Home photographs and Crystal Kizor logo assets in this project were supplied for the assessment.
